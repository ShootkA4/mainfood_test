# Календарь компании — Битрикс iFrame

## Как это работает

Приложение автоматически определяет где запущено:

| Режим | События из | CORS | Авторизация |
|-------|-----------|------|------------|
| **Битрикс** | Real API (`BX24.callMethod`) | Нет проблемы | Пользователь портала |
| **GitHub Pages** | Mock данные | — | Нет |

В режиме Битрикста:
- `BX24` доступен автоматически при загрузке
- Все запросы идут через `BX24.callMethod()` — **без CORS**
- `BX24.fitWindow()` растягивает iframe по контенту
- Кнопка "Открыть в Битриксе" — переходит к событию

## Установка на GitHub Pages

### 1. Создать репо на GitHub

```bash
cd E:\Bitrix_MAIN
git init
git add .
git commit -m "calendar app"
git remote add origin https://github.com/YOUR_USER/bitrix-calendar.git
git push -u origin main
```

### 2. Включить GitHub Pages

Settings → Pages → Source: main branch / `/docs` folder → Save

Получишь URL вида: `https://YOUR_USER.github.io/bitrix-calendar/`

## Добавление в портал Битрикс

### Способ 1: Custom Application (рекомендуется)

1. Зайди в **Администрирование** → **Настройки** → **Приложения**
2. Нажми **"Добавить приложение"**
3. Выбери тип: **Стандартное приложение (iframe)**
4. Введи:
   - Название: `Календарь компании`
   - URL: `https://YOUR_USER.github.io/bitrix-calendar/index.html`
   - Иконку (опционально)
5. Выбери раздел где показывать (например "Календари" или "Компания")
6. Сохрани

### Способ 2: Через маркетплейс

Если опубликуешь на marketplace.bitrix24.com:
- Приложение доступно всем пользователям портала
- Автоматическая установка из маркетплейса

## Настройка прав доступа

Вебхук не нужен! При работе в iframe используется контекст авторизованного пользователя.

Чтобы видеть групповые календари:
1. У пользователя должны быть права на чтение календарей
2. Настроить в: **Календари** → нужный календарь → **Доступ**

## Что видит пользователь

- 🔵 Статус "● Битрикс" в шапке
- Реальные события из всех доступных календарей
- Клики открывают детали + кнопку "Открыть в Битриксе"

## Если пусто

Проверь консоль (F12):
```
[Календарь] Режим: БИТРИКС iFRAME
[Календарий] Найдено календарей: 3
[Календарий] "Проект Х": 5 событий
...
```

## Локальная разработка

Запусти локальный сервер:
```bash
cd E:\Bitrix_MAIN
python -m http.server 8080
# или
npx serve .
```

Открой `http://localhost:8080` — будет демо режим с mock данными.

Для теста в iframe — настрой reverse proxy к localhost:8080.
